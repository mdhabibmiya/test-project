# test.project

Project notes for Cursor.

## Tech stack

- **Runtime:** Node.js
- **Language now:** TypeScript. New code is written in TypeScript (`.ts`), with types and a `tsconfig.json`.
- **Language later:** JavaScript. The TypeScript sources will be converted to plain JavaScript (`.js`) when that step starts. Until then, do not add a parallel JavaScript source tree.

## Workspace

This folder is a new Node.js project. There is no application source here yet.

## How to work in this project

- Keep changes inside this folder.
- Write application code in TypeScript until the JavaScript conversion is requested.
- Match the style of existing code once files are added.
- Prefer small, focused edits over broad rewrites.
- Do not commit, push, or change git config unless asked.
